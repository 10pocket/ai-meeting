# UI ルール

対象は Web UI (`public/index.html`) と録画ページ (`extension/recorder.html`)。使う人は自分ひとりで、仕事の合間に「録画を探す、議事録を読む、該当の発言へ飛ぶ」ことが主な用途。見た目は静かにし、強調は文字起こしの時刻チップ 1 か所に絞る。

## 実装方針

- フレームワークは使わない。素の HTML / CSS / JS で、ビルド手順を持たない。
- 2 つの画面でデザイントークン (`:root` の変数) を同じ値で複製する。片方を変えたらもう片方も変える。
- 次のどれかが必要になったら React 等を再検討する。画面が 4 つ以上になる。画面をまたぐ状態が増える。話者名の編集など、入力と一覧が連動する機能が入る。

## トークン

| 種類 | 値 |
|---|---|
| 色 | `--bg` 地、`--surface` 面、`--ink` 本文、`--muted` 補助文字、`--line` 罫線、`--accent` 操作と時刻 (ミント系の青緑)、`--rec` 録画中・削除、`--warn` 処理中、`--ok` 完了 |
| 余白 | 4 / 8 / 12 / 16 / 24 / 32px。この段階だけを使う |
| 角丸 | 操作部品は 6px、面 (パネル) は 8px。この 2 種だけ |
| 文字 | 本文 14px、行間 1.7。見出し 20px (画面タイトル) と 16px (節)。補助 12px。時刻は等幅 12px |
| 書体 | 日本語のゴシック体 1 系統 (Hiragino Sans, Noto Sans JP, Yu Gothic UI)。時刻だけ等幅 |
| 配色 | OS の設定に従い、明暗を `prefers-color-scheme` で切り替える。文字は地に対して 4.5:1 以上 |

## 部品

- **ボタン**: 高さ 36px 以上。通常は枠線、主操作は `--accent` で塗る (1 画面に 1 つまで)、削除は `--rec` の文字色。無効時は薄くしてカーソルも変える。
- **コピーボタン**: アイコンだけの 36px の正方形にする。通常は補助色のクリップボード。押すとチェックに変わり、アクセント色で 2 秒表示して戻す。成功の文言は画面に出さず、スクリーンリーダー向けにだけ読み上げる。失敗したときだけ、赤で理由を文字で書く。
- **リンク**: ファイルを取得するリンク (拡張の zip など) は、ボタンと同じ見た目にする。文中のリンクは下線を付ける。
- **状態表示**: 色だけで伝えない。点と文字 (録画中 / 処理中 / 完了 / エラー) を必ず併記する。
- **パネル**: 面の色、1px の罫線、8px の角丸。影は付けない。見出しの右に、その内容への操作 (コピーなど) を置く。
- **時刻チップ**: `[hh:mm:ss]` は押せる等幅のチップにする。押すと動画がその位置へ飛ぶ。

## 文言

- 文は常体で短く、ボタンは動作を書く。「送信」ではなく「停止して送信」、「コピー」ではなく「Markdown をコピー」。
- 同じ動作は流れの最後まで同じ語で呼ぶ。「コピー」を押したら「コピーしました」と返す。
- エラーは、何が起きたかと、次にすることを書く。謝らず、曖昧にしない。
- 空の画面では、次に何をすればよいかを書く。

## アクセシビリティ

- キーボードで操作でき、フォーカスは 2px の輪郭線で必ず見える。
- 状態の変化 (録画中の経過、完了、エラー) は `aria-live` で読み上げられるようにする。
- 動きは使わない。入れる場合は `prefers-reduced-motion` で止める。
- 幅 760px 以下では一覧を上、本文を下の 1 列にする。
